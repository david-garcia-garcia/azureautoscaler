## MODIFIED Requirements

### Requirement: Live catalog folder naming
Each live spec under `openspec/specs/` SHALL use a folder id with exactly four underscore-separated parts `{root}_{domain}_{component}_{spec-name}` declared in `openspec/specs/domains.md`. Kebab-case live folder ids listed in the change proposal SHALL be renamed to their mapped 4-part ids without altering normative requirement text.
